安裝日語語音的方式

  • Windows　設定 → 時間與語言 → 語言與地區 → 新增「日本語」，於語言選項中勾選「語音」，裝好後重開瀏覽器
  • macOS　系統設定 → 輔助使用 → 朗讀內容 → 系統語音 → 管理語音 → 下載日文（Kyoko／Otoya）
  • iPhone／iPad　設定 → 輔助使用 → 朗讀內容 → 語音 → 加入日文
  • Android　設定 → 系統 → 語言與輸入 → 文字轉語音輸出 → 安裝日文語音資料
